# PASSPORT-AUTOMATION-SYSTEM
The Passport Automation System is a web-based application designed to automate and simplify the passport application and verification process. The system provides an online platform where applicants can register, enter their personal details, upload required documents, submit passport applications, and track their application status.
This project is created for academic demonstration purpose only
